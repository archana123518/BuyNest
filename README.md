# 🛍️ Buynest – Full Stack E-Commerce Website

Buynest is a full-stack e-commerce web application developed to provide users with a simple and convenient online shopping experience.

## 🚀 Technologies Used

**Frontend**
- React.js
- JavaScript
- HTML
- CSS

**Backend**
- ASP.NET Core Web API
- C#

**Database**
- PostgreSQL
- Entity Framework Core

## ✨ Features

- User Registration and Login
- Product Browsing and Search
- Product Categories
- Shopping Cart Management
- Order Management
- Payment Management
- Product Reviews
- User Profile and Address Management
- Admin Dashboard
- Role-Based Authorization

## 📁 Project Structure

- `BuynestFrontend` – React frontend application
- `BuynestAPI` – ASP.NET Core Web API backend

## ⚙️ How to Run the Project

**Frontend**
1. Navigate to the `BuynestFrontend` folder.
2. Run `npm install`.
3. Run `npm run dev`.

**Backend**
1. Navigate to the `BuynestAPI` folder.
2. Configure the PostgreSQL connection string and JWT settings.
3. Run `dotnet restore`.
4. Run `dotnet run`.
